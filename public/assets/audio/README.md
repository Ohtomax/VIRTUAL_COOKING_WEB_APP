# Audio Assets

This folder should contain background music and sound effects for the game.

## Required Files:

- `background-music.mp3` - Main background music that loops during gameplay

## Optional Files:

- Sound effects for cooking actions (chopping, frying, etc.)
- UI sounds (button clicks, transitions)
- Achievement unlock sounds

## Note:

Add your background music file as `background-music.mp3` in this folder to enable the music feature in the game.
